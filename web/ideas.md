# ChessIQ — Intelligence in Motion

## Ground-truth design direction

The product is **ChessIQ**, a chess intelligence platform built around understanding. The flagship should communicate a readable progression from **position → calculation → evaluation → understanding**, not present a generic dashboard or a decorative game lobby.

### Design Movement

**Technical editorial minimalism** meets a premium analytical instrument. The visual system uses depth, geometry, typography, and deliberate signal hierarchy to make complicated chess analysis feel calm and intelligible.

### Core Principles

1. **Intelligence stays visible.** Evaluation, tactical events, and explanation are tied together in one coherent Analysis Thread.
2. **The board is the evidence.** The chess position dominates every responsive layout; all analysis supports the position rather than competing with it.
3. **Signals are sparse and meaningful.** Electric violet marks calculation and selected intelligence; teal carries engine activity and continuity; semantic colors remain exceptional.
4. **A product of motion, not spectacle.** The IQ Pulse makes state changes legible through small, coordinated movement instead of decorative animation.

### Color Philosophy

Deep graphite gives the application authority and creates a quiet field for chess calculation. Warm white preserves long-form readability, while cool gray provides a technical secondary layer. **IQ Violet** is the product’s primary signal: it belongs to calculation, active analysis, and decisive insight. Teal provides a calm parallel signal for engine readiness and progress. Brilliant moments use a violet-gold alloy, while mistakes and blunders have distinct label, icon, and semantic treatments—never color alone.

### Layout Paradigm

The analysis view is a **calculation corridor**: board and evaluation spine form the central evidence plane, the right rail turns raw engine state into understanding, and the timeline/graph form a continuous analytical trace below. On mobile, that corridor becomes a deliberate vertical sequence: board, evaluation, move control, engine insight, explanation, and graph. Secondary detail belongs in an on-demand sheet, not a permanent stack.

### Signature Elements

1. **IQ Pulse:** a thin, responsive violet line whose inflections make engine activity, a brilliant move, or a major evaluation change perceptible.
2. **Calculation Grid:** a barely visible geometric coordinate field placed in low-information backgrounds and transition surfaces.
3. **Analysis Thread:** a narrow teal/violet connective thread that binds selected move, evaluation delta, tactical event, and explanatory feedback.

### Interaction Philosophy

Every control responds like a tuned analytical tool: immediate on a chess interaction, gently perceptible for a state change, and fully keyboard reachable. Beginner and advanced information modes let users choose conceptual clarity or engine detail without changing the underlying product language.

### Animation

The motion system has four levels: micro (120ms), fast (180ms), normal (280ms), and major (420ms). Transitions use transform and opacity where possible; evaluation changes use a measured linear sweep; graph focus and classification labels settle with a strong ease-out. The IQ Pulse is the only continuous brand motion and pauses under reduced-motion preference.

### Typography System

**Space Grotesk** provides high-intent display and heading typography. **Inter** gives compact, lucid product copy. **JetBrains Mono** is reserved for SAN notation, evaluations, depths, node counts, labels, and calibration markers. Hierarchy remains left-aligned, operational, and legible at dense analysis sizes.

### Brand Essence

**ChessIQ turns engine calculation into understandable chess improvement.** It is **incisive, composed, and lucid**.

### Brand Voice

ChessIQ speaks in precise game-state language with a coaching consequence. Headlines are short; actions explain their chess purpose; no visible copy uses onboarding filler. Example lines: **“A better move was available.”** and **“The position changed here.”**

### Wordmark & Logo

The ChessIQ mark is an abstract calculation glyph built from C/Q geometry and a single connected node rather than a literal chess piece. The wordmark uses an intentionally spaced `CHESSIQ` lockup with a minute IQ Pulse underline and works as a companion to the mark, never as a default-font label.

### Signature Brand Color

**IQ Violet — `#8B5CF6`** — represents active calculation and decisive analytical insight.
